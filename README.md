# Аналитика сети веломагазинов: Поиск точек роста выручки

Комплексный анализ розничной сети из 3 магазинов (2016–2018). Выявлены проблемы логистики, оптимизирован ассортимент и предложены решения для роста выручки.

## Ключевые результаты
* **Корневая причина просадки 2018 года:** выявлено $1.37M упущенной выручки из-за дефицита товара в пиковый сезон (апрель).
* **Принцип Парето:** 68 товаров (21% ассортимента) генерируют 80% выручки.
* **Дисбаланс магазинов:** Baldwin Bikes (NY) формирует 70% выручки сети.
* **Эффективность персонала:** выявлен лучший продавец по upsell-метрике (4.83 товара/чек), чьи скрипты рекомендованы к тиражированию.
* **RFM-сегментация:** выделен сегмент "At Risk" (23.5% клиентов), генерирующий 34% выручки, требующий срочной win-back кампании.

## Основные разделы анализа
1. **EDA и подготовка данных:** проверка качества, анализ причин пропусков в `shipped_date` (связь со статусами заказов), очистка.
2. **Временной анализ:** выявление сезонности (пик — март-апрель), поиск аномалий.
3. **Анализ логистики:** расчет упущенной выручки из-за дефицита, определение проблемных SKU.
4. **Товарная аналитика:** выручка по категориям, топ-10 хитов и аутсайдеров, кривая Парето.
5. **Сравнение магазинов и персонала:** декомпозиция выручки, анализ среднего чека и upsell-метрик.
6. **Клиентская аналитика:** RFM-сегментация, анализ повторных покупок, география клиентов.
